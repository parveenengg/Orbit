How to Contribute

1. Repository & Issues

Review the Repository and explore the Issues board. Choose or discuss an issue you'd like to tackle. Ask for assignment where applicable.

2. Fork & Branch

Fork the repository to your own GitHub account and create a new branch for your feature or bug fix.

3. Build & Test

Implement your changes, build the browser locally, and test rigorously to ensure Orbit's performance remains unaffected.

4. Pull Request & Review

Submit a Pull Request. The maintainers will review your code. Please note that PR acceptance is not guaranteed, but we value all contributions and feedback.
